## 물리 가정

아래 값은 **Tesla에서 확인한 사양이 아닙니다.** `src/physics.js`와 설정 UI에서 바꿀 수 있습니다.

| 항목 | 가정 |
| --- | --- |
| 질량 | 1,900 kg, 가스 사용 후에도 고정 |
| 휠베이스 / 윤거 | 2.78 m / 1.70 m |
| 타이어 반경 | 0.355 m |
| 저속 구동 합력 | 25 kN, 속도에 따라 감소 |
| 전진 부스트 | 72 kN 추가 합력 |
| 흡착 | 중량의 2.0배 기본값 + 속도에 따른 단순 항 |
| 상승 추진 | 중량의 2.8배 기본값, 중력이 별도로 작용 |
| 가스 | 무제한. 실제 탱크의 압력·분사 시간 모델이 아님 |
| 공기저항 | 공기밀도 1.225 kg/m³, CdA 0.66 m² 가정 |
| 공중 회전 | 피치 1.35 rad/s, 롤 1.85 rad/s, 요 1.15 rad/s를 목표로 관성에 따라 토크 제어. 축별 토크 상한은 18 / 4.2 / 12 kN·m |
| 시간 간격 | 1/120초 |

차량 외형은 절차적 메시로 만든 시각적 근사입니다. 프레임·서스펜션·노즐 배치의 설계도가 아니며, 화면의 노즐 10개도 제조사 CAD 좌표를 의미하지 않습니다. 소리는 실제 녹음이 아닌 합성 EV·바람·가스 소리입니다.

실차 수준의 재현도를 높이려면 정식 사용 허가가 있는 상세 3D 모델, 정확한 제원과 관성 텐서, 타이어 곡선, 팬의 차고별 성능, 압력별 노즐 추력·분사 위치와 제어 로그가 필요합니다.

## 카메라와 조작 설계

카메라 구현은 [Unity Cinemachine Orbital Follow](https://docs.unity3d.com/Packages/com.unity.cinemachine@3.1/manual/CinemachineOrbitalFollow.html)의 수평·수직·반경 축, world-up 바인딩과 지연된 재정렬 개념, [Unreal Engine Spring Arm](https://dev.epicgames.com/documentation/en-us/unreal-engine/using-spring-arm-components-in-unreal-engine)의 장애물 회피 개념을 참고했습니다. 웹 입력의 드래그·휠·감쇠는 [Three.js OrbitControls](https://threejs.org/docs/pages/OrbitControls.html)의 인터랙션 범주를 참고하되, 주행 중 차량 추적과 물리 충돌 검사는 별도 구현했습니다.

차량 방향과 마우스 회전을 매 프레임 더하지 않고 궤도 각도를 독립적으로 보관합니다. 카메라 타깃은 임계 감쇠로 추적하고, 원래 거리로 복귀할 때도 완만하게 이동합니다. 우클릭 컨텍스트 메뉴는 게임 캔버스에서 차단합니다.

2026-10-17 개선에서 좌우 조향 부호를 수정하고, 렌더러의 바퀴 변환 갱신이 Cannon-es의 접지 상태를 지우던 문제를 제거했습니다. 바퀴와 차체는 같은 고정 물리 단계의 정보를 보간해서 그립니다. 곡선 노면과 경사로는 렌더링·충돌체 생성 좌표를 공유합니다.
