## 동작을 어떻게 옮겼는가

| 공개 시연에서 보고된 동작 | 구현 | 한계 |
| --- | --- | --- |
| 흡착으로 수직·거꾸로 노면에 붙어 주행 | 접촉 중 차체 아래 방향으로 힘 적용 | 팬 유량, 밀폐 성능과 차고에 따른 힘 변화를 모름 |
| 램프 끝에서 거꾸로 이탈 | 실제 충돌 도로가 끝나면 중력으로 낙하 | 도로 형상·높이·속도는 영상 실측값이 아님 |
| 추진기를 사용한 상승과 회전 | 차체 좌표계의 힘·토크, 유한 가스 예산 | 실제 노즐별 추력과 제어기를 알 수 없어 합력으로 근사 |
| 장애물 도약과 착지 | 이륙·착지 경사로와 고체 장애물 | 실제 Tesla 차량 행렬의 모델·크기를 복제하지 않음 |
| 가속 시험 | 시뮬레이션에서 26.8224 m/s 도달 시간 측정 | rollout·타이어·온도 등 실차 측정 조건을 재현하지 않음 |

## 물리 가정

아래 값은 **Tesla에서 확인한 사양이 아닙니다.** `src/physics.js`와 설정 UI에서 바꿀 수 있습니다.

| 항목 | 가정 |
| --- | --- |
| 질량 | 1,900 kg, 가스 사용 후에도 고정 |
| 휠베이스 / 윤거 | 2.78 m / 1.70 m |
| 타이어 반경 | 0.355 m |
| 저속 구동 합력 | 25 kN, 속도에 따라 감소 |
| 전진 부스트 | 72 kN 추가 합력 |
| 흡착 | 중량의 2.0배 기본값 + 속도에 따른 단순 항 |
| 상승 추진 | 중량의 2.8배 기본값, 중력이 별도로 작용 |
| 가스 | 전진 부스트 단독 8초 분량의 정규화된 예산. 질량 kg·압력 bar의 실물 탱크 모델이 아님 |
| 공기저항 | 공기밀도 1.225 kg/m³, CdA 0.66 m² 가정 |
| 공중 회전 | 피치 11.5 kN·m, 롤 8.5 kN·m, 요 6 kN·m의 합성 토크 |
| 시간 간격 | 1/120초 |

차량 외형은 절차적 메시로 만든 시각적 근사입니다. 프레임·서스펜션·노즐 배치의 설계도가 아니며, 화면의 노즐 10개도 제조사 CAD 좌표를 의미하지 않습니다. 소리는 실제 녹음이 아닌 합성 EV·바람·가스 소리입니다.

실차 수준의 재현도를 높이려면 정식 사용 허가가 있는 상세 3D 모델, 정확한 제원과 관성 텐서, 타이어 곡선, 팬의 차고별 성능, 압력별 노즐 추력·분사 위치와 제어 로그가 필요합니다.
